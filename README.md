# 우사기 데스크톱 펫 (Windows · macOS)

우사기가 사용 중인 프로그램 위에서 화면을 돌아다니고, 음악이 나오면 춤을 추거나 랩을 합니다. 트레이에서 고른 앱 창은 제목 표시줄을 잡고 실제로 끌고 갑니다.

- 대상: Windows 10/11 x64. 일반 사용자 권한으로 실행됩니다(관리자 권한 불필요).
- 기술: C++17, Win32, WASAPI loopback, WIC, CMake, MSVC

## 빌드

필요한 것: Visual Studio 2022 Build Tools(“C++를 사용한 데스크톱 개발” 워크로드, Windows SDK, CMake 포함)

```bat
build.bat
```

또는 직접:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

결과물은 `build\Release\usagi_pet.exe`입니다. 빌드 후 단계에서 `assets\`와 `settings.ini`가 EXE 옆으로 복사됩니다.

## 실행과 배포

`usagi_pet.exe`를 실행하면 작업 표시줄 트레이에 우사기 아이콘이 생깁니다. 모든 조작은 트레이 아이콘을 클릭해서 합니다.

### 다른 사람에게 배포하기 (EXE 하나)
스프라이트, `usagi.ini`, 기본 `settings.ini`, 아이콘이 모두 EXE 안에 리소스로 들어 있습니다. 그래서 **EXE 파일 하나만 받아서 더블클릭하면 바로 실행**됩니다. 설치도, VC++ 재배포 패키지도 필요 없습니다(CRT 정적 링크).

배포 파일은 `dist\` 폴더에 있습니다.

| 파일 | 내용 |
|---|---|
| `dist\UsagiDesktopPet.exe` | 이것만 보내도 됩니다 (약 2 MB) |
| `dist\UsagiDesktopPet-1.0.0-win64.zip` | EXE와 사용자용 `사용법.txt`를 담은 압축 파일 |

- **실행할 때 파일을 찾는 순서:**
  - EXE 옆에 `assets\`와 `settings.ini`가 있으면 그것을 씁니다(개발용 빌드 폴더).
  - 없으면 EXE 안의 에셋을 `%LOCALAPPDATA%\UsagiDesktopPet\assets\`에 풀어서 씁니다. 내용이 바뀌었을 때만 다시 씁니다.
  - 설정은 `%LOCALAPPDATA%\UsagiDesktopPet\settings.ini`에 기본값으로 한 번만 만들고, 사용자가 고친 값은 덮어쓰지 않습니다.
- **API 키:** 개발자의 Gemini API 키는 EXE에 들어가지 않습니다. 받은 사람이 처음 말을 걸 때 자기 키를 넣습니다.
- **SmartScreen:** 코드 서명이 없어서 인터넷에서 받으면 처음 실행할 때 SmartScreen 경고가 뜹니다. “추가 정보 → 실행”을 누르면 됩니다. 경고를 없애려면 코드 서명 인증서가 필요합니다.
- **다시 만드는 법:** `build.bat`로 빌드한 뒤 `build\Release\usagi_pet.exe`를 `UsagiDesktopPet.exe`로 복사합니다.
- **요구 사항:** Windows 10 1703 이상, 64비트.

## macOS 버전

`mac/` 폴더에 Swift/AppKit으로 다시 만든 Mac 판이 있습니다. macOS 12 이상, Apple 실리콘·Intel 공용(유니버설)입니다.

**설치:** [Releases](https://github.com/12dsdwasda/usagi-desktop-pet/releases/latest)에서 `UsagiDesktopPet-<버전>-mac.zip`을 받아 풀고, `UsagiDesktopPet.app`을 응용 프로그램 폴더로 옮깁니다.

Apple 개발자 서명이 없는 앱이라서 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜹니다. 다음 중 하나로 여세요.
- 앱을 **우클릭 → 열기 → 열기**
- 또는 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**
- 또는 터미널에서 `xattr -cr /Applications/UsagiDesktopPet.app`

실행하면 Dock 아이콘 없이 **메뉴 막대에 우사기 아이콘**이 생기고, 메뉴는 Windows 트레이 메뉴와 같습니다. 대화창 단축키는 ⌃⌥U입니다.

**권한:**
- **손쉬운 사용**(메뉴 → "손쉬운 사용 권한 허용하기…"): 다른 앱 창 끌기와, 던질 때 클릭·키보드를 막는 데 필요합니다. 권한이 없어도 걷기, 춤, 잡기·던지기, 포인터 가져가기, 포인터 던지기는 됩니다. 이때 입력 막기는 마우스 이동만 막힙니다.
- **자동화(스포티파이/Music)**: 처음 곡을 읽을 때 macOS가 묻습니다. 허용해야 따라 부르기가 됩니다.

**Windows 판과 다른 점:**
- 음악 반응은 소리를 듣는 방식이 아니라 **스포티파이나 Apple Music이 재생 중일 때** 춤·랩을 합니다. 유튜브 같은 브라우저 소리에는 반응하지 않습니다.
- 녹음한 목소리와 메모장 장난은 없습니다. 에이전트의 `write_note`는 문서/우사기 메모에 저장한 뒤 텍스트 편집기로 엽니다.
- Gemini 키는 키체인에 저장됩니다. `GEMINI_API_KEY` 환경 변수도 읽습니다.
- 설정은 `defaults`(UserDefaults)에 저장됩니다. 예: `defaults write io.github.12dsdwasda.usagi-desktop-pet sizePt 180`

**직접 빌드**(Xcode 명령줄 도구 필요): `bash mac/build.sh` → `dist-mac/`. GitHub Actions(`.github/workflows/mac.yml`)가 push할 때마다 빌드하고, 8초간 실행해 화면을 캡처합니다.

## 동작 방식

### 화면 위를 걷는 우사기
- `WS_EX_LAYERED` 창에 `UpdateLayeredWindow`로 픽셀별 알파를 그립니다. 투명한 배경이 사각형으로 보이지 않습니다.
- `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`를 사용합니다. 클릭은 뒤의 앱으로 통과하고, 키보드 포커스를 가져가지 않으며, 작업 표시줄에도 나타나지 않습니다.
- 우사기가 있는 모니터의 작업 영역 바닥(작업 표시줄 바로 위)을 걷습니다. 가끔 멈추고, 가장자리에 닿으면 방향을 바꿉니다.
- Per-Monitor V2 DPI를 지원합니다. 모니터마다 DPI에 맞는 크기로 다시 그립니다. 보조 모니터의 음수 좌표를 처리하고, 모니터가 분리되면 가장 가까운 작업 영역으로 옮깁니다.
- 전체 화면 앱(게임·영상)이 앞에 있으면 그 모니터에서는 잠시 숨깁니다. `settings.ini`의 `hideOnFullscreen`으로 끌 수 있습니다.

### 음악에 맞춘 춤과 랩
- WASAPI loopback으로 기본 출력 장치의 재생음을 읽습니다. 마이크 권한이 필요 없습니다. 분석은 메모리에서만 하고, 오디오를 파일로 저장하거나 외부로 보내지 않습니다.
- 소리 크기(dBFS)와 지속 시간을 함께 봅니다. 기본값은 약 0.7초 이상 이어지면 반응하고, 약 1.5초 조용하면 걷기로 돌아갑니다. 그래서 짧은 알림음에는 반응하지 않습니다.
- 150Hz 이하 저역에서 킥 온셋을 검출하고, 템포와 위상을 추정합니다. 박자가 안정적으로 잡히면 주요 포즈(0·2번 프레임)를 박자에 맞추고, 잡히지 않으면 기본 프레임 속도로 부드럽게 반복합니다. 소리 크기에 따라 프레임을 바로 바꾸지 않으므로 덜덜 떨리지 않습니다.
- 기본 출력 장치가 바뀌면(이어폰 연결 등) 알림을 받아 캡처를 다시 연결합니다. 장치 오류가 나면 2초마다 재시도합니다. 감지에 실패해도 걷기와 창 끌기는 계속 동작합니다.

> **주의:** 1차 버전은 일정 시간 이어지는 시스템 재생음이면 모두 반응합니다. 그래서 음악이 아닌 긴 영상, 화상 회의, 영상 통화의 대화 소리에도 춤을 출 수 있습니다. 장르나 음성은 구분하지 않습니다. 원치 않으면 트레이에서 음악 모드를 ‘끄기’로 바꾸거나 `thresholdDb`·`startSec`를 높이세요.

### 스포티파이 노래 따라 부르기
스포티파이에서 노래가 나오면 우사기가 마이크를 들고(랩 동작) **가사를 재생 위치에 맞춰 한 줄씩 말풍선으로** 부릅니다.

- **곡 정보:**
  - Windows 미디어 컨트롤(GSMTC)에서 지금 곡, 가수, 앨범, 재생 위치를 0.4초마다 읽습니다.
  - 스포티파이 로그인이나 개발자 키가 필요 없습니다. 데스크톱 앱과 Microsoft Store 앱 모두 됩니다.
- **가사:**
  - 무료 공개 가사 DB인 [LRCLIB](https://lrclib.net)에서 시간이 맞춰진 가사(LRC)를 받습니다.
  - 정확히 찾고, 없으면 꼬리표(“- Remastered”, “(feat. …)”)를 뗀 제목으로 다시 검색합니다.
  - 곡 길이가 8초 넘게 다른 버전은 버립니다.
  - 받은 가사는 프로그램이 켜져 있는 동안 기억합니다.
- **곡이 바뀔 때:** 말풍선에 “♪ 곡 제목”이 뜹니다.
  - 가사가 있으면 소리 감지와 상관없이 음악 상태가 되어 따라 부릅니다.
  - 가사가 없으면 평소처럼 소리에 맞춰 춤만 춥니다.
- **전송되는 정보:** LRCLIB로는 곡 제목, 가수, 앨범, 길이만 전송됩니다.
- **에이전트 도구:**
  - `spotify_now_playing`: 지금 곡과 위치, 가사가 있는지 알려줍니다.
  - `spotify_control`: 재생, 일시정지, 다음 곡, 이전 곡.
  - `spotify_search`: 스포티파이 앱에서 검색을 엽니다. 곡을 자동으로 재생하지는 못하므로 결과에서 사용자가 눌러야 합니다.
- **설정:** 트레이 메뉴 **스포티파이 노래 따라 부르기**에서 켜고 끕니다. 메뉴에 지금 곡이 표시됩니다.
  - `settings.ini`의 `[sing] spotifyOnly=0`으로 하면 브라우저 같은 다른 미디어 앱의 곡도 따라 부릅니다.
  - 가사 타이밍이 어긋나면 `offsetSec`(초)로 맞춥니다.

### 실제 앱 창 끌기
1. 트레이 메뉴에는 현재 보이고 정상적으로 옮길 수 있는 최상위 앱 창이 제목으로 나옵니다. 크롬은 브라우저 창 전체가 대상입니다.
2. 다음 창은 목록에서 빠집니다: 최소화·최대화·전체 화면 창, 시스템 UI(작업 표시줄·바탕화면 등), 도구 창, 소유된 대화상자, 다른 가상 데스크톱의 창, 관리자 권한으로 실행된 창(UIPI 때문에 옮길 수 없음), 응답 없는 창.
3. 우사기가 오른쪽·왼쪽 중 여유가 더 많은 쪽의 제목 표시줄 가장자리로 걸어갑니다. 손이 닿으면 끌기 애니메이션으로 바뀝니다.
4. `SetWindowPos(SWP_NOSIZE | SWP_NOZORDER | SWP_NOACTIVATE | SWP_ASYNCWINDOWPOS)`로 창을 옮깁니다. 크기, 활성 상태, Z 순서는 바뀌지 않습니다. 우사기 위치는 매 프레임 실제 창 테두리(DWM extended frame bounds)를 기준으로 계산합니다. 그래서 손과 창 가장자리가 같이 움직입니다.
5. 이동 거리는 150~250 DIP 사이에서 정합니다. 화면 여유가 부족하면 창과 우사기가 화면 안에 남도록 줄입니다. 여유가 전혀 없으면 제자리에서 당기기만 합니다. 이동은 가로 방향으로만 하므로 제목 표시줄에는 계속 접근할 수 있습니다.
6. 다음 경우에는 즉시 놓습니다: 이동 중 창이 닫히거나 최소화·최대화될 때, 사용자가 직접 창을 잡고 끌 때, 창 크기가 바뀔 때, 다른 프로그램이 창을 옮기거나 이동이 실패할 때.
7. 끄는 동안 음악이 시작돼도 끌기를 계속합니다. 끝난 뒤 바닥으로 돌아와서 현재 음악 모드와 재생 상태를 적용합니다.

### 장난 모드
장난 모드가 켜져 있으면 우사기가 걷거나 쉬는 동안 정해진 간격마다 장난을 하나 고릅니다.

- **창 끌고 가기:** 옮길 수 있는 창 중 하나를 골라 끌고 갑니다. 지금 쓰고 있는 앞 창은 고르지 않고, 포커스도 바꾸지 않습니다. 동작 방식과 제외되는 창은 위의 ‘실제 앱 창 끌기’와 같습니다.
- **메모장 놀리기:** 아래 조건을 모두 만족할 때만 합니다.
  - 열린 메모장이 하나도 없을 것. 사용자가 쓰던 메모장이나 문서에는 절대 입력하지 않습니다.
  - 사용자가 45초(`notepadIdleSec`) 이상 키보드·마우스를 쓰지 않았을 것. 트레이의 ‘지금 장난치기’는 이 조건 없이 바로 시작합니다.

  조건이 맞으면 새 메모장을 열고, 우사기가 그 아래쪽으로 걸어가 놀리는 문장을 한 글자씩 칩니다. 글자는 `WM_CHAR` 메시지로 메모장 편집 영역에만 보내므로, 키보드 포커스를 쓰지 않고 다른 앱 입력에도 끼어들지 않습니다. 타이핑 중 사용자가 키보드나 마우스를 만지면 즉시 멈춥니다(“하아?”). 다 쓴 메모장은 그대로 남겨 두니, 닫을 때 ‘저장 안 함’을 고르면 됩니다.

### 마우스로 우사기 잡기
우사기 몸(투명한 부분 제외)을 왼쪽 버튼으로 꾹 누른 채 움직이거나 0.3초 이상 누르고 있으면 우사기가 마우스에 잡힙니다(“하아? 하아?”).

- **잡혀 있는 동안:** 잡은 자리를 그대로 붙든 채 포인터를 따라오며 다리를 버둥거립니다.
- **놓으면:** 버튼을 놓으면 그 아래 모니터의 작업 영역 바닥까지 떨어지고, 착지하면 “푸루!” 하고 다시 걷습니다.
- **던지기:** 잡은 채 포인터를 휙 움직이다 놓으면 우사기가 날아갑니다(“우라우라!”).
  - 속도는 놓기 직전 약 0.1초 동안의 포인터 속도를 씁니다. 최대 5000 DIP/초입니다.
  - 중력과 공기 저항을 받아 포물선으로 날아갑니다.
  - 작업 영역의 옆 벽과 천장에서는 튕깁니다. 그쪽에 다른 모니터가 있으면 튕기지 않고 넘어갑니다.
  - 바닥에 세게 떨어지면 최대 4번까지 통통 튄 뒤 착지합니다(“푸루야~”).
  - 포인터를 멈춘 채 놓으면 던지지 않고 그냥 떨어집니다.
- **짧은 클릭:** 우사기 위를 짧게 클릭하면 잡지 않고, 같은 자리에 클릭을 다시 보내 뒤의 앱이 받게 합니다. 그래서 평소처럼 클릭이 통과합니다.
- **하던 일:** 창 끌기·메모장 장난·포인터 가져가기 중에 잡으면 그 일은 그 자리에서 그만둡니다.
- **구현:** 저수준 마우스 후크(`WH_MOUSE_LL`)로 우사기 위에서 누른 경우만 가로챕니다.
  - 그 밖의 마우스 입력은 손대지 않고 그대로 넘깁니다.
  - 후크가 응답 지연으로 시스템에서 끊기면, 2초 안에 이를 알아채 우사기를 내려놓고 후크를 다시 설치합니다.
- **끄는 법:** `settings.ini`의 `[pet] grabbable=0`. 이렇게 하면 우사기 위 클릭은 처음처럼 모두 그대로 통과합니다.

### 때리면 화내고 포인터 던지기
우사기를 빠르게 연달아 클릭하면 때린 것으로 봅니다. 클릭 사이 간격은 더블클릭 시간(최소 0.5초) 안이어야 합니다.

- **클릭 횟수별 반응:**
  - 1번: 평소처럼 뒤의 앱으로 클릭이 전달됩니다.
  - 2번: 대화창이 열립니다. 세 번째 클릭이 오는지 잠깐 기다렸다가 엽니다.
  - 3번 이상: 때린 것입니다.
- **화내기:** 우사기가 빨갛게 달아오르고 부들부들 떨며 발을 구릅니다(“하아?! 하아?!”). 하던 끌기, 장난, 포인터 쫓기는 그만둡니다.
- **포인터 던지기:**
  - 약 1초 뒤 포인터를 손으로 낚아채 뒤로 젖혔다가, 화면 반대쪽 위로 포물선을 그리며 던집니다(“우라!!”).
  - 날아가는 순간부터 포인터에 **불이 붙습니다.** 착지한 뒤에도 불타는 포인터가 몸부림치고, 우사기는 춤추며 깔깔 웃습니다(“야하! 야하!”).
- **입력 막힘:**
  - 던지는 동안과 그 뒤 **5초 동안 마우스와 키보드가 먹지 않습니다.** 저수준 마우스·키보드 후크로 막습니다.
  - 버튼·키를 **떼는** 입력은 통과시킵니다. 그래서 Ctrl 같은 키가 눌린 채로 남지 않습니다.
  - `Ctrl+Alt+Del`은 Windows가 직접 처리하므로 언제나 동작합니다.
  - 정해진 시간이 지나면 상태와 상관없이 막기를 풉니다. 프로그램이 멈추면 Windows가 후크를 건너뛰므로 입력이 계속 막힌 채로 남지 않습니다.
- **던지지 않는 경우:** 포인터를 잡을 수 없는 상황에서는 “흥!” 하고 화만 냅니다. 메뉴가 열려 있거나, 앱이 마우스를 잡고 있거나, 포인터가 숨겨져 있거나, 게임 등에서 포인터가 한 영역에 갇혀 있는 경우입니다.
- **끄는 법:**
  - 트레이 메뉴 **때리면 화내기**에서 끕니다.
  - `settings.ini`의 `[angry]`에서 `enabled`, `hits`(3~20), `blockSec`(0~10초)를 바꿉니다.

### 마우스 포인터 가져가기
기본값으로 10초마다 우사기가 마우스 포인터로 달려가 잡고(“야하!” → “우라!”), 여유가 많은 쪽으로 150~250 DIP 끌고 간 뒤 놓습니다(“이~”). 간격은 지난번 장난이 끝난 뒤부터 셉니다.

- **끝까지 쫓기:** 포기하지 않습니다. 오래 쫓을수록 빨라집니다(걷기 속도의 4배에서 최대 12배). 따라잡은 뒤에도 포인터가 움직이는 동안은 손을 붙인 채 따라다니다가, 사용자가 잠깐(0.12초) 멈추는 순간 잡습니다.
- **가까우면 바로:** 포인터가 우사기 몸 근처(약 60 DIP 안)에 있으면 10초 쿨타임 없이 바로 잡으러 갑니다. 춤추는 중에도 마찬가지입니다.

사용자 작업을 망치지 않도록:

- **시작하지 않는 때:**
  - 포인터가 0.5초(가까울 때는 0.25초) 이상 멈춰 있지 않을 때(마우스를 쓰는 중)
  - 마우스 버튼을 누르고 있을 때(드래그·선택 중)
  - 메뉴가 열려 있거나 창을 옮기는 중일 때, 앱이 마우스를 잡고 있을 때
  - 포인터가 숨겨져 있거나 한 영역에 갇혀 있을 때(게임, 입력 중 포인터 숨김)
  - 전체 화면 앱 위, 캐릭터를 숨겼을 때, 이동 일시정지 중, 춤·창 끌기·메모장 장난 중일 때
- **바로 놓는 때:** 잡고 끄는 도중 사용자가 마우스를 움직이거나 버튼을 누르면 즉시 놓습니다(“하아? 하아?”). 드래그나 클릭이 엉뚱한 곳에 떨어지지 않게 하기 위해서입니다. 놓은 뒤에도 포인터가 가까이 있으면 쿨타임 없이 다시 잡으러 옵니다. 쫓는 도중 버튼을 누르고 있으면, 놓을 때까지 따라다니기만 합니다.
- **끄는 법:** 트레이 메뉴 체크 해제, 또는 `settings.ini`의 `[cursor] enabled=0`

### 말풍선 표현

사용자가 정리해 준 표현을 상황에 맞춰 씁니다.

| 표현 | 나오는 때 |
|---|---|
| 야하! / 아하! | 끌고 갈 창을 스스로 찾았을 때 / 장난칠 메모장을 찾았을 때 |
| 우라! / 우라우라 | 창을 잡을 때, 끄는 중, 메모장 타이핑을 시작할 때, 음악이 시작될 때(랩 모드는 “우라우라!”) |
| 푸루! / 푸루야 | 트레이에서 시킨 일을 받았을 때(“알겠어”), 음악 모드를 바꿨을 때, 타이핑 중 응원할 때 |
| 하아? / 하아? 하아? | 끌기나 장난이 방해받았을 때(취소, 창 닫힘, 사용자 입력). 사용자가 창을 직접 잡아채면 “하아? 하아?” |
| 미야아아~ / 미야야야~ | 처음 실행했을 때, 자리를 비웠던 사용자가 돌아왔을 때 / 숨겼던 캐릭터를 다시 보이게 했을 때 |
| 쥬르리… | 앞 창 제목에 음식 관련 단어(맛집, 레시피, 배달, 치킨, 피자, recipe 등)가 있을 때. 2분에 한 번까지 |
| 이~ | 창을 다 끌고 갔을 때, 메모장에 다 썼을 때(“이거 봐봐”) |
| 구우구우~ | 사용자가 3분(`sleepIdleSec`) 이상 입력이 없을 때 제자리에서 졸며 |

‘아푸’(물에 들어갈 때)는 어울리는 상황이 없어 쓰지 않았습니다. 별도의 수면 스프라이트가 없어서, 졸 때는 걷기의 서 있는 프레임을 쓰고 “구우구우~” 말풍선만 띄웁니다. 메모장에 칠 때도 타이핑 전용 스프라이트가 없어서, 팔을 앞으로 모은 춤 프레임(1·3번)을 번갈아 보여 줍니다.

### 녹음한 목소리
트레이의 **목소리 녹음…** 에서 말풍선 표현마다 목소리를 녹음해 둘 수 있습니다. 녹음한 표현은 말풍선이 뜰 때 그 목소리가 함께 나옵니다.

녹음 방법:
1. 왼쪽 목록에서 표현을 고릅니다. ●는 녹음됨, ○는 녹음 안 됨입니다.
2. **녹음하기**를 누르고 말합니다.
3. 다시 누르거나 5초가 지나면 녹음이 끝나고, 바로 한 번 들려줍니다.

- **저장 방식:** 앞뒤 조용한 부분을 잘라내고 소리 크기를 맞춰 저장합니다. **들어보기**와 **지우기**로 다시 확인하거나 지울 수 있습니다.
- **녹음이 없을 때:** 비슷한 표현의 녹음으로 대신 틉니다. 예를 들어 ‘하아? 하아?’가 없으면 ‘하아?’, ‘우라우라’가 없으면 ‘우라!’를 씁니다. 대신 쓸 녹음도 없으면 말풍선만 뜹니다.
- **저장 위치:** `%LOCALAPPDATA%\UsagiDesktopPet\voices\<id>.wav`입니다. **녹음 폴더 열기**로 열 수 있습니다. 직접 만든 WAV 파일을 같은 이름으로 넣고 앱을 다시 실행해도 됩니다.
  - id 목록: `yaha` 야하!, `aha` 아하!, `ura` 우라!, `uraura` 우라우라, `puru` 푸루!, `puruya` 푸루야~, `haa` 하아?, `haahaa` 하아? 하아?, `miyaaa` 미야아아~, `miyayaya` 미야야야~, `jururi` 쥬르리…, `ii` 이~, `guuguu` 구우구우~
- **마이크:** 녹음 버튼을 누른 동안에만 기본 녹음 장치(마이크)를 씁니다. 마이크 접근이 막혀 있으면 *Windows 설정 > 개인 정보 및 보안 > 마이크*에서 ‘데스크톱 앱이 마이크에 액세스하도록 허용’을 켜 주세요. 음악 감지는 여전히 마이크를 쓰지 않습니다.
- **재생 규칙:**
  - 같은 목소리는 2~5초 안에 다시 틀지 않습니다. ‘구우구우~’는 20초 간격입니다.
  - 캐릭터가 숨겨져 있거나 전체 화면 앱이 앞에 있을 때는 틀지 않습니다.
  - 우사기 목소리가 나오는 동안에는 음악 감지를 잠시 멈춥니다. 그래서 자기 목소리를 음악으로 알고 춤추지 않습니다.

### 우사기 에이전트 (Gemini)
우사기에게 말을 걸면 Google Gemini가 답하고, 필요하면 정해진 도구로 컴퓨터에서 직접 일을 합니다.

- **대화 여는 법:**
  - 우사기를 더블클릭합니다. 첫 번째 클릭은 평소처럼 뒤의 앱으로 전달됩니다.
  - `Ctrl+Alt+U` 단축키를 누릅니다.
  - 트레이 메뉴에서 **우사기와 대화…**를 고릅니다.
- **대답:** 대화창에 기록되고 우사기 머리 위 말풍선에도 뜹니다. 녹음한 목소리와 맞는 말이면 목소리도 나옵니다. 기다리는 동안 말풍선에 “음…”이 뜹니다.
- **대화창:** 우사기 옆, 공간이 더 넓은 쪽에 뜹니다. Enter로 보내고 Esc로 닫습니다. **새 대화**를 누르면 기억을 비웁니다. 닫아도 프로그램이 켜져 있는 동안은 대화를 기억합니다.

**할 수 있는 일 (도구)**

| 도구 | 하는 일 |
|---|---|
| `open_url` / `search_web` | 브라우저로 주소를 열거나 구글 검색 결과를 띄웁니다. 검색 결과 내용은 읽지 못합니다 |
| `open_app` | 메모장, 계산기, 그림판, 파일 탐색기, 설정, 작업 관리자, 화면 캡처, 브라우저 |
| `open_folder` | 바탕 화면, 문서, 다운로드, 사진, 음악, 동영상 |
| `set_timer` / `list_timers` | 1초~24시간 타이머. 시간이 되면 “띵!” 소리와 말풍선으로 알립니다. 프로그램을 끄면 사라집니다 |
| `get_status` | 날짜·시각, 배터리, 메모리 사용률, PC 켜진 시간, 우사기 상태 |
| `list_windows` / `drag_window` | 열린 창 제목을 보고 그 창을 직접 끌고 갑니다 |
| `set_music_mode` | 춤 / 랩 / 끄기 |
| `media_control` | 재생·일시정지, 다음·이전 곡, 볼륨 올리기·내리기·음소거 |
| `write_note` | 메모장을 열고 우사기가 직접 빠르게 타이핑합니다. 메모장이 이미 열려 있으면 `문서\우사기 메모\날짜-시각.txt`로 저장해 엽니다 |
| `copy_to_clipboard` / `read_clipboard` | 클립보드에 복사하거나 읽습니다. 읽기는 사용자가 요청했을 때만 하도록 지시돼 있습니다 |
| `pet_action` | 장난치기, 포인터 가져가기, 하던 일 멈추기 |

- **안전 범위:**
  - 파일 삭제, 프로그램 설치, 명령 실행, 결제·로그인 같은 도구는 일부러 넣지 않았습니다.
  - 한 번 물어볼 때 도구 호출은 최대 6번까지입니다.
- **모델:**
  - `settings.ini`의 `[agent] models` 순서대로 씁니다. 기본값은 `gemini-3-flash-preview`, `gemini-flash-latest`, `gemini-3.5-flash`입니다.
  - 과부하(503)나 한도 초과(429)가 오면 다음 모델로 넘어갑니다.
- **API 키:**
  - 트레이 메뉴 **Gemini API 키…**(대화창의 **키** 버튼과 같음)나 `usagi_pet.exe --set-gemini-key <키>`로 넣습니다.
  - `%LOCALAPPDATA%\UsagiDesktopPet\gemini.key`에 DPAPI로 암호화해 저장합니다. 이 PC의 이 Windows 사용자 계정에서만 풀 수 있습니다.
  - 소스 코드, `settings.ini`, 로그에는 키가 들어가지 않습니다.
  - 파일이 없으면 환경 변수 `GEMINI_API_KEY`를 씁니다. 지우려면 `--clear-gemini-key`를 씁니다.
- **개인정보:**
  - 대화 내용과 도구 결과(예: 창 제목 목록, 요청한 클립보드 내용)는 답을 만들기 위해 Google Gemini API로 전송됩니다.
  - 그 밖의 화면 내용, 소리, 녹음은 보내지 않습니다.

## 에셋

원본은 `..\usagi-animation`에 있으며 수정하지 않았습니다. 복사본은 `assets\original\`에 있습니다. 실행용 에셋은 아래 명령으로 다시 만들 수 있습니다(Pillow, NumPy, SciPy 필요).

```bat
python tools\prepare_assets.py ..\usagi-animation assets
```

- **원본 스프라이트:** 모두 1536×384 RGBA이며, 384×384 프레임 4개가 가로로 배열되어 있습니다. 프레임 시간은 `animations.json` 값을 그대로 씁니다.
- **발바닥 정렬:** 각 프레임에서 몸통(가장 큰 연결 영역)의 맨 아래가 y=344에 오도록 세로로 정렬했습니다. 춤의 점프 프레임(0·2번)은 다른 프레임과 같은 양만 옮겨서 점프 높이를 유지했습니다.
- **좌우 반전:** 걷기는 이동 방향에 따라 좌우를 반전합니다. 끌기는 어느 쪽 가장자리를 잡느냐에 따라 반전하고, 손 위치도 함께 반전해서 보정합니다.
- **끌기 스프라이트(`drag.png`):** 원본에는 가짜 창이 같이 그려져 있어 실제 창과 겹쳐 보입니다.
  - 그래서 흰색·라벤더 창 영역과 그 테두리를 투명하게 지운 파생 스프라이트를 만들었습니다.
  - 4프레임 모두 분리했고, 다른 프레임으로 대체한 것은 없습니다.
  - 손이 닿는 점(`gripX`, `gripY`)이 프레임마다 같도록 가로로 정렬했습니다. 그래서 끄는 동안 창이 손에서 떨리지 않습니다.
  - 창과 맞닿아 있던 손끝 테두리는 조금 얇아졌지만, 실행 중에는 실제 창 가장자리가 그 자리에 옵니다.

## 테스트·자동화용 명령줄

이미 실행 중인 인스턴스에 명령을 보낼 수 있습니다.

```
usagi_pet.exe --log C:\temp\pet.log   (처음 실행할 때만: 상태 로그 기록)
usagi_pet.exe --drag-title "메모장"     (제목에 이 글자가 들어간 창 끌기)
usagi_pet.exe --drag-hwnd 1A2B3C       (창 핸들, 16진수)
usagi_pet.exe --cancel-drag
usagi_pet.exe --mode dance|rap|off
usagi_pet.exe --pause | --hide | --show
usagi_pet.exe --device-restart         (오디오 캡처 재연결 강제 실행)
usagi_pet.exe --prank now|drag|notepad|off|sometimes|often
usagi_pet.exe --prank notepad-test     (테스트용: 사용자 입력이 있어도 메모장 타이핑 계속)
usagi_pet.exe --say "우라!"             (말풍선 띄우기)
usagi_pet.exe --chat "5분 타이머 맞춰줘" (대화창을 열고 에이전트에게 보내기)
usagi_pet.exe --chat-open
usagi_pet.exe --angry                  (때린 것처럼 화내고 포인터 던지기)
usagi_pet.exe --set-gemini-key <키>    (키를 암호화해 저장만 하고 끝남)
usagi_pet.exe --clear-gemini-key
usagi_pet.exe --quit
```
